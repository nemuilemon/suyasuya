# 動作確認用の睡眠画面（架空）

「記録する」の読み取り（Gemini による OCR）を試すための、**画像生成で作った架空の睡眠アプリ画面**。
実在の人の記録でも、実在のアプリの画面でもない。ロゴや実在のブランド名は入れていない。

審査用のテストアカウントで「記録する」→「スクリーンショットを読み取る」に、どれか 1 枚をアップロードすれば試せる。

| `watch-style/4-iphone-nap-ja.png` | iPhone のヘルスケア風（日本語） | 昼寝 | 13:52〜14:34、38 分（10月14日） |

機種ごとに画面の形がばらばらでも読めること、日本語・英語の両方、昼寝の判別を試せるように作った。

## 試し方

1. 画像を 1 枚ダウンロードする
2. 「記録する」→「スクリーンショットを読み取る」で選び、「アップロードして読み取る」
3. 読み取りが終わると「読み取り・確認待ち」に候補が出る。「候補 1 を確認」を押す
4. 画像と抽出結果を見ながら、睡眠日（起床した日）と種類（主睡眠／昼寝）を選び、「承認して保存」

承認するまで記録にはならない。読み取りを誤っても、そのまま分析には入らない。

## 生成の記録

- `prompt.txt`、`nemuri-sleep-v1.raw.jpg`：「Nemuri」の生成指示と、生成直後の画像
- `watch-style/raw/`：`watch-style/` の各画像の生成指示（`*.txt`）、時刻の軸を直した指示（`*-fix.txt`）、生成直後の画像
