# suyasuya

**睡眠を支える agent。**
記録・分析・動機付け・通知を 1 つの agent が回す。

第 5 回 Agentic AI Hackathon with Google Cloud 応募作品（開発中）。

## つくるもの

睡眠アプリの多くは、user に「つける」ことを求める。
だが**記録という行為そのものが、対象への注意になる**。
寝つきのように、意識するほど遠のく種類のものでは、それが逆に働くことがある。

睡眠はデバイスが自動で測ってくれる。だから suyasuya が user に求めるのは
**スクリーンショットを 1 枚上げること、それだけ**にする。
残りは agent の側でやる —— 読み取り、蓄積、傾向の把握、声のかけ方の判断まで。

| | |
|---|---|
| **記録** | 上がってきた画像から睡眠データを読み取り、構造化して蓄積する |
| **分析** | 傾向を読む（就寝時刻のばらつき、睡眠段階の構成、スコアとの関係） |
| **動機付け** | その日に効く行動を 1 つだけ提案する |
| **通知** | 届くべき時刻に届ける |

スコアを毎朝突きつけて習慣化を迫る形は取らない。
**agent が読んで、必要なときにだけ声をかける。**

## 状態

開発中。データの取り込みと agent loop から着手している。

## 技術

web app として作る。

- **Go** —— agent loop は framework を使わず自前で書く
- **Gemini** —— 画像からの読み取りと、提案文の生成
- **Google Cloud（Compute Engine）** —— 公開先
